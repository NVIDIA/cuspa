### 0.1.0 {small}`the-future`


* First release of cuspa: GPU point-in-polygon assignment and transcript aggregation for spatial omics {smaller}`S Dicks`
* {class}`~cuspa.Polygons` holds Polygon and MultiPolygon geometry in flat GeoArrow-style buffers, and {class}`~cuspa.SpatialIndex` indexes it on the GPU {smaller}`S Dicks`
* {func}`~cuspa.tl.assign_points` assigns each point to one polygon. Both it and {func}`~cuspa.tl.overlap_pairs` take CuPy arrays or CUDA PyTorch tensors {smaller}`S Dicks`
* {func}`~cuspa.tl.overlap_pairs` returns every point-polygon match, including results with more than 2{sup}`31` - 1 pairs {pr}`11` {smaller}`S Dicks`
* {func}`~cuspa.tl.aggregate_to_cells` builds a sparse cells-by-genes {class}`~cuspa.tl.CSRMatrix` from batches of transcripts. It converts to CuPy or PyTorch sparse matrices without a copy through host memory {smaller}`S Dicks`
* Add the {mod}`cuspa.io` adapters {func}`~cuspa.io.from_geoarrow`, {func}`~cuspa.io.from_geopandas`, {func}`~cuspa.io.from_spatialdata`, and {func}`~cuspa.io.transcripts_from_spatialdata` {smaller}`S Dicks`
